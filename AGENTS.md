## 1. Project snapshot
- **What**: The last beacon of Gondor. Every 15 minutes it merges the lab's inventory-rendered topology with live health (Gatus checks, VictoriaMetrics uptime, Alertmanager alerts) into one `status.json`, validates it fail-closed, and PUTs it to the piercemoore.com S3 bucket under `status/`. Push only: nothing public reaches into the lab.
- **Runtime**: Python 3.13 · FastAPI · Pydantic v2 · httpx · boto3 · uv · ruff · mypy --strict · pytest.
- **Infra**: One image (`Dockerfile`), built by Gitea Actions on the lab's pull mirror (`.gitea/workflows/ci.yml`), run in the isengard ring from a homelab-inventory stack. The topology arrives as a ConfigMap rendered by homelab-inventory.
- **Owner**: Pierce (@rex). Work is tracked in Rivendell (GitHub issues on rex/halifirien); nothing else.
- **Non-goals**: serving the public (the website does that), storing history (VictoriaMetrics has it), hiding topology (full disclosure is the point, VIBE D2), any inbound path from the internet.

## 2. Setup

```bash
make setup        # uv sync --frozen, .env from .env.example, typecheck
make test         # pytest (respx fakes every source; moto fakes S3)
make preview      # one dry-run cycle against the sources in .env, prints the document
make schema       # after ANY change to app/document.py: regenerate the committed schema
```

## 7. Security (hard stops)

- No secrets committed. `detect-secrets` + gitleaks enforce.
- Parameterized queries only.
- No wildcard IAM. No `0.0.0.0/0` except 443 on ALBs.
- MCP credentials never touch `.env` — they resolve at connect time through
  `scripts/mcp/op-headers.sh` and degrade to OAuth / anonymous tier.
- See `.claude/rules/security.md` for full checklist.

## 9. Things agents get wrong here

<!-- Update whenever an agent makes the same mistake twice. Start empty. -->

- `app/document.py` IS the public contract. Adding a field there publishes it to the internet on the next cycle once `make schema` runs; `make typecheck` fails until the committed schema matches the models.
- Full disclosure of topology is intended (VIBE D2): don't "sanitize" names, addresses or VLANs. Secrets are the only thing the gate exists to stop.
- Test fixtures that look like credentials must be assembled at run time (`"AK" + "IA" + ...`): pre-commit's detect-secrets/gitleaks and GitHub push protection scan the source.
- The code names no lab hosts or URLs; they reach the pod as env from the homelab-inventory stack. The lab's Gitea repo is a pull mirror: never add it as a git remote.
- `unknown` is a real state (nothing observes the node). Don't map it to `ok` to make the page greener; add a Gatus check in the inventory instead.
- The auto-lint hook runs `ruff --fix` after every edit and deletes imports not used *yet*: write the usage first, the import second.
